# Aston boot 5 (2026-11-09)

Build: main 1ed895b, CI run 42596717622, root image 158d94bc with the payload menu entry "iPadOS diag (logs)"
(`log-sys=1 log-power=1`). The phone booted iPadOS, ran for about 480 s and was restarted from SpringBoard.

## BootLog

`read-sheng-log.py --decode`: 240 rounds, 0 write errors, state 2.

- Data: `[data mount capacity] status=0 total=8589934592 free=6893985792 available=6893985792`; store `D st=2 er=0`,
  548523 changed pages. The kernel sees an 8 GiB Data volume with 6.4 GiB free.
- CPU: idle domains at 1 to 3 percent busy and minimum frequency, 70 to 100 mA pack current. Interaction loads all
  domains (96 to 130 s at 100 percent while Settings opened). GPU DCVS reports 0 percent busy.
- Battery: the pack current is negative for the whole run, peak discharge 2.3 A, temperature up to 37.8 C. Every
  `[charger]` and `[usb]` row is zero: the audio DSP, which runs the battery manager and charging, was not started.
- Restart: panic `vnode_rele_ext: usecount -ve`, v_type 8 (VBAD). Backtrace against the CI kernel: `reboot` →
  `reboot_kernel` → `vfs_unmountall` → `unmount_callback` → `dounmount` → `vflush` → `vnode_reclaim_internal` →
  `vclean` → `vnode_update_identity` → `vnode_rele_internal`, in the system pass on the sealed OS volume. Data was
  unmounted cleanly in the first pass.

## Data volume

`pull-aston-data.py` (read only, pages hashed on the phone), `build-aston-data-image.py` and `apfs-read.py`:
container xid 4141, one unencrypted volume "Data", 14260 files.

- No `/containers/Data/Application` and no `/containers/Shared/AppGroup`.
- `mobile/Library/Preferences/com.apple.migration.plist` comes from the seed
  (`DMUserDataDisposition = {SyntheticDidUpgrade = 0, buildVersion = 24A446}`), so datamigrator skipped the first-boot
  migration that registers the system apps and makes their containers.
- CrashReporter: Files (10) and DockFolderViewService (78) crash in `+[FILocalStorageNode sharedNodeWithDomain:]` with
  a nil local-storage URL; dasd (50) aborts in `-[NSURL initFileURLWithPath:]`; iconservicesagent (32) faults in
  CoreImage; Preferences was terminated by the watchdog while waiting on a Mach message.
- The system clock starts at 1970 on every boot.

## Changes

- `aston-migration-rerun.patch`: with `sheng-rerun-migration=1` (menu "Rebuild app data") the migration marker is
  removed before launchd starts, so that boot runs the data migration once.
- `aston-reboot-readonly-unmount.patch`: the last unmount pass leaves read-only volumes mounted.
- `sheng-adsp=2` and the aston adspslpi size (0x4880000) in `AdspProbe.cpp`: all 57 load segments of modem_a's
  adsp.mdt fit; sheng's size leaves one outside.
